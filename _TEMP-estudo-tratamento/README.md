# _TEMP-estudo-tratamento

**Pasta descartável.** Estudo de tratamento (cor, contraste, pele, grão) sobre uma
foto pessoal, com referências do Savee e matriz de testes no Magnific.

Para excluir quando acabar:

```
git rm -r _TEMP-estudo-tratamento && git commit -m "remove estudo temporario"
```

## Regra de conteúdo

Nada de imagem aqui. O repositório é público e o `AGENTS.md` bloqueia publicação de
material fotográfico e metadados derivados. Esta pasta guarda **só texto**: diagnóstico,
papéis das referências, parâmetros reais e prompts. As imagens vivem no Magnific
(biblioteca do usuário) e na board privada do Savee.

## Arquivos

| `02-matriz-testes-magnific.md` | Rota de upscale/relight — arquivada, ver `05` |
